## 前言

我們是東華三院李潤田紀念中學的學生。今年，我們的團隊成員有謝明心、賴栩漩和梁灝晞。這是我們的技術文件。我們的團隊由一群對科技和機器人充滿熱情的學生組成。我們希望探索如何運用機器人，透過創新設計、技術和多元視角來解決現實世界的問題。在即將到來的世界機器人大賽（WRO）中，我們將展現我們的創造力和技術實力，力爭取得優異成績。

因此，我們在世界機器人競賽（WRO）中的主要目標是展現我們的問題解決能力和團隊合作。我們致力於設計和開發能夠解決現實世界問題的機器人。我們相信，只有不斷挑戰自我，才能取得更大的成功。每場比賽都是學習的機會，我們將充分利用這些經驗，持續改進，追求卓越。
